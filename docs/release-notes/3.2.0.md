# FORGE LAUNCHER 3.2.0

## WHAT'S NEW

* Clearer GitHub errors. When an update check or download fails, the message now says why:
  GitHub limiting requests (HTTP 403/429), GitHub having problems (5xx) or a file not found (404).
  The log and the problem report include the status code and the address that failed (#7).
* Temporary GitHub errors are retried automatically, up to 3 times.
* No more duplicated editions. Old files in res/editions that the new Forge version doesn't
  include are removed when Forge is installed or updated. Forge renamed some edition files
  (M19/M20/M21) and the old copies made parts of Forge crash, for example the set filter in the
  deck editor (#8). If you have this problem, update or reinstall Forge once to fix it.
* Keep up to 3 previous Forge versions (was 2).
* Help > Report a problem now offers to open the Forge Launcher issues page on GitHub.

---

Forge Launcher installs, updates and starts Forge (https://card-forge.github.io/forge/)
on Windows.

This zip contains two files. Keep them together, in the same folder:

* Forge Launcher.exe
* ICSharpCode.SharpZipLib.dll

## REQUIREMENTS

* Windows 10 or 11 (Windows 7 SP1 and 8.1 work with .NET Framework 4.8 installed).
* Java 17 or later, which Forge needs to run.
* A folder you can write to. Don't use C:\Program Files.

## IF YOU ALREADY HAVE FORGE

1. Unzip "Forge Launcher.exe" and "ICSharpCode.SharpZipLib.dll" into your Forge folder, the one that contains forge.exe.
2. Run "Forge Launcher.exe".
3. Choose Snapshot (daily builds) or Release (stable versions) at the top right.

The launcher detects your Forge version by itself and tells you if there is an update.

## IF YOU DON'T HAVE FORGE YET

1. Create an empty folder, for example C:\Games\Forge
2. Unzip "Forge Launcher.exe" and "ICSharpCode.SharpZipLib.dll" into it.
3. Run "Forge Launcher.exe".
4. Choose Snapshot or Release.
5. Optional: turn on "Portable install" to keep your decks, settings and card images
   inside this folder instead of in your Windows user profile.
6. Click "Install Forge". The download is about 300 MB.

## IF YOU USED AN OLDER FORGE LAUNCHER

Replace the old "Forge Launcher.exe" and "ICSharpCode.SharpZipLib.dll" with the ones in this zip, or use Help > Check for Forge Launcher updates. Your update channel and settings are kept.

## EVERYDAY USE

* Launch Forge (or press Enter) starts Forge and closes the launcher.
* Check for updates (or press F5) looks for a newer Forge build.
* The gear button (or Ctrl+,) opens Settings.

Close Forge before updating: Windows doesn't allow replacing files that are in use.

## GOING BACK TO A PREVIOUS VERSION

If a new Forge version doesn't work well for you, the launcher can take you back.
This only works with versions installed after you turn the option on:

1. Open Settings and set "Keep previous Forge versions" to 1, 2 or 3.
   Each saved version takes about 300 MB.
2. When you need it, use Forge > Restore a previous version.

Your decks, preferences and card images are always kept.

## IF SOMETHING GOES WRONG

* Forge doesn't start or freezes on the splash screen:
  Forge > Reset Forge preferences.
* To ask for help: Help > Report a problem. It copies a report to the clipboard;
  paste it in a new issue at https://github.com/churrufli/forgelauncher/issues
  with a short description of what happened.

## FILES CREATED BY THE LAUNCHER

Everything the launcher creates is in the "fldata" folder, next to forge.exe:
settings, the log (launcher.log) and saved Forge versions.

## UNINSTALLING

Settings > Uninstall Forge Launcher. It removes the launcher, its DLL and the fldata
folder. Forge and your decks, preferences and card images are not touched.
